# E-Accessories - Gadgets & Tech Accessories Landing Page

A sleek, responsive e-commerce landing page created for digital gear, tech peripherals, and electronic accessories. Built with modern HTML5, clean CSS3 layouts, custom typography, and integrated Bootstrap Icons[cite: 4].

---

## 🚀 Live Demo

[View Live Project](https://azzmath-12.github.io/Project-E-Accessories/)

---

## 📌 Features

- **Hero Showcase**: Full-bleed background header featuring prominent product highlights, callouts, and primary call-to-action buttons[cite: 4].
- **Service Highlights**: Structured feature cards with custom circular counters and accent borders.
- **Discover & Metrics**: Side-by-side product imagery and feature milestones showcasing key metrics.
- **Brand & Creator Profile**: Modern profile card section with circular avatar presentation and custom social links.
- **Support & Assistance**: High-contrast dark block featuring centered icons and support details.
- **Visual Description Grid**: Split-panel content card with detailed product pointers and accompanying imagery[cite: 4].
- **Contact & Inquiry Form**: Functional layout complete with form fields, message box, and overlay social channels.
- **Fully Responsive**: Media queries tailored for fluid presentation across desktop, tablet, and mobile viewport widths.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic web markup and document hierarchy[cite: 4].
- **CSS3**: Custom CSS variables, Flexbox layouts, media queries, and component styling[cite: 4].
- **Bootstrap Icons**: Vector iconography for tech accessories and navigation elements[cite: 4].
